# YouTube upload

1. youtube.com → sign in with the channel you want to show (ideally a brand channel "Enigma Play") → **Create → Upload video** → choose `enigma-play-demo-raw.webm`.
2. **Title** (max 100):
```
Enigma Play: Email Popup Game for Shopify - demo
```
3. **Description**:
```
Enigma Play turns your Shopify popup into a short game. Visitors enter their email, play a quick round and win a unique, single-use discount code that is auto-applied at checkout.

In this demo:
- A visitor plays and wins a discount code
- Setup in the editor: store colors, triggers, reward tiers
- Analytics: emails, wins and revenue per popup

Free until the popup brings you $500 in sales a month.
Install: https://apps.shopify.com/game-discount
```
4. **Thumbnail**: upload `02-winning-code.png` (or leave the one YouTube picks).
5. **Audience**: "No, it's not made for kids".
6. **Visibility**: **Public** (or Unlisted if you don't want it in YouTube search; the App Store link works either way).
7. **Publish** → copy the video link (Share → Copy) → paste it into the listing.
